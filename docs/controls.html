nidhogg controls

Draft mapping of Chompi TAPE's panel onto an OMX-27 and a ShieldXL norns. The OMX-27 runs Quixotic7's firmware (v1.15.4 or later) in REMOTE mode, so the norns can light every key and draw on its OLED. TEMPO and WAVE use the same Chompi panel, so the same layout serves all three modes. Dashed yellow parts are proposals still open.

note key (slot) black key, its shift function below CHOMPI / looper knob (pages) proposal, open

OMX-27

Note names are Chompi's (C3 to C5). Every key LED shows what Chompi's LED for that key shows: bank colours, playing voices, menu state. AUX shows Chompi's CHOMPI LED. B3 is left unused since it's easy to hit by accident. Pots send 14-bit values in REMOTE mode. AUX + hold the encoder button leaves REMOTE mode.

norns (ShieldXL)

Laid out like the ShieldXL. The screen shows which way the Play/Record switch is set.
